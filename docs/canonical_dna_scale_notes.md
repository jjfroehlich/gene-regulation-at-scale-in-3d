# Canonical DNA Scale Notes

The current canonical scene should not be reinterpreted as a full genomic actin locus yet.

Current canonical values:

- DNA: 1,900 bp, 258.34 mm contour length, 0.136 mm/bp.
- mRNA: 1,852 nt, 222.24 mm contour length.
- Working interpretation: short/exon-scale actin-region DNA.

Human ACTB comparison:

- Practical full-gene default: NCBI Gene ACTB / Gene ID 60 and the Ensembl canonical transcript span are about 3,454 bp.
- At the current scene scale, 3,454 bp would be about 469.7 mm.
- At 1:10, 3,454 bp would be about 47.0 mm.
- Including a 500 bp upstream promoter region gives 3,954 bp, or about 537.7 mm at the current scene scale.
- Ensembl canonical ACTB has 6 exons totaling about 1,812 bp, so the current 1,900 bp DNA is close to an exon-scale representation.
- The broad Ensembl ACTB gene object spans about 37,494 bp, which would be about 5.10 m at current scale or 510 mm at 1:10; this is not the recommended default for the sculpture.
